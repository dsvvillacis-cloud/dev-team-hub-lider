# dev-team-hub

Portal colaborativo en Markdown desarrollado en pareja para gestionar los perfiles individuales del equipo y compartir herramientas recomendadas.

## Estructura del Proyecto
- `README.md`: Página principal y descripción general del portal.
- `equipo/`: Fichas de presentación individual de cada integrante.
- `recursos/`: Herramientas y recursos recomendados por el equipo.
